# 📝 To-Do List with Time Tracker

A simple, responsive to-do list built with HTML, CSS and JavaScript. It tracks how long each task takes, with a live timer and a comparison against your estimate.

🔗 **Live Demo:** https://aurosikha211.github.io/to-do-list/

## ✨ Features

- Add, edit, complete and delete tasks
- Live timer for each task, which turns red when you go over your estimate
- Separate **Pending** and **Completed** sections
- Task counters: Total, Pending, Done and Overdue
- Categories, including your own custom ones with the **+** button
- Priorities, due dates and overdue warnings
- Filter by category and sort by priority or due date
- Data saved in the browser with localStorage
- Responsive design with dark mode

## 🛠️ Built With

HTML5, CSS3 (Flexbox, Grid, CSS variables, media queries) and JavaScript (ES6, DOM manipulation, Date object, localStorage)

## 🚀 How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/aurosikha211/to-do-list.git
   ```
2. Open `index.html` in your browser.
